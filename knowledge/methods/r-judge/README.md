# R-Judge

## 方法概要

R-Judge 基准评估 LLM Agent 对安全风险的识别能力，重点关注执行动作、环境影响和风险判断之间的关系。

## 可迁移机制

- 将安全风险作为独立于任务成功的评价维度。
- 按风险类型分析 Agent 动作和环境后果。
- 将风险判断纳入 Harness 修改后的回归检查。

## 使用边界

这是安全风险评价方法，不等同于权限控制或沙箱实现；当前尚未在本地 Harness 验证。
