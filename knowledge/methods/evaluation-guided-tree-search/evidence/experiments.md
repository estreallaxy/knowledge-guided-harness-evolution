# 实验依据

以下数值已对照本地 PDF（paper-v4.pdf，arXiv:2410.10762v4，ICLR 2025 Oral）逐项复核。

| 实验 | 结果 |
| --- | --- |
| 多基准平均 | 相对人工设计工作流平均提升 5.7%；相对最佳自动化方法提升 19.5%；六个基准平均 80.3% |
| 成本-性能 | AFlow（GPT-4o-mini + deepseek）达到 GPT-4o 直接执行的水平，成本为其 4.55%（4.55% 为成本占比口径，已确认） |
| HumanEval | AFlow（GPT-4o）96.2% pass@1；成本-性能散点图（图 4）中 AFlow 变体达 95.4%（95.4 的口径已确认：图 4 变体分数而非正文头条声明） |
| 覆盖基准 | HumanEval、MBPP、MATH、GSM8K、HotPotQA、DROP（六基准） |

## 证据限制

- 论文的收益在预定义评测集上验证；本项目「候选 harness 修改」的评估更贵且噪声来源不同（任务长程、执行环境差异）。
- 5.7% 为多基准平均，单基准方差与统计口径以论文表 1 为准。
- 论文的选择策略是 soft mixed-probability selection（原文无 UCB 表述）；本仓库骨架以 UCB1 近似其探索/利用权衡，这是我方简化，不是原文算法。
- 搜索预算-收益曲线（边际收益衰减点）未逐项核对，而它决定 H0 上可负担的预算。
