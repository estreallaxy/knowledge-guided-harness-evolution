# HiAgent

## 方法概要

HiAgent 使用分层工作记忆管理长时域 Agent 任务，将长轨迹压缩为可复用的子任务级记忆，降低上下文膨胀和执行遗忘。

## 可迁移机制

- 将长任务拆分为可管理的子任务。
- 为子任务维护局部工作记忆。
- 在层级边界汇总状态并传递给后续执行。

## 使用边界

需要明确的子任务边界和可序列化的工作记忆；本地代码尚未接入共同 H0。
