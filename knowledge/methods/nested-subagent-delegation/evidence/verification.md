## 主张边界

可以引用的结论是：对话驱动的协调者循环与嵌套子会话是多 agent 编排的成熟机制，已在大规模开源系统（AutoGen 及其后继）中验证其工程可用性。

不能引用为已证实结论的内容包括：该机制能提高本研究 H0 的任务通过率、其 token 开销低于单 agent 循环、或该机制优于其他编排方案。这些都需要本地实验。
