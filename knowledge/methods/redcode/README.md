# RedCode

## 方法概要

RedCode 评估代码 Agent 执行风险，覆盖危险代码生成、执行行为和安全防护，是运行隔离与权限边界方向的可复用安全评测材料。

## 可迁移机制

- 将代码生成风险与实际执行风险分开记录。
- 在执行前后检查危险行为和环境影响。
- 将安全策略作为独立回归维度。

## 使用边界

主要面向代码 Agent 和代码执行环境；迁移到通用 Harness 前需明确执行沙箱和权限模型。
