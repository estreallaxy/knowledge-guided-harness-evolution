# Open Grounded Planning

## 方法概要

Open Grounded Planning 将规划与外部知识、工具调用和执行约束结合，适合提取“规划—调用—反馈”的执行循环机制。

## 可迁移机制

- 在计划生成前显式绑定可用知识和环境状态。
- 将工具调用结果反馈给后续计划步骤。
- 保存计划、证据和执行结果之间的对应关系。

## 使用边界
