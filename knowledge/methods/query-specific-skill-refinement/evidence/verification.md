## 主张边界

可以引用的结论是：当检索结果已有较高相关性和覆盖度时，任务级探索与 Skill 重写可能提高执行表现和 Skill 加载率；初始覆盖不足或 agent 自评错误时，收益可能消失或转为退化。

不能引用为已证实结论的内容包括：该机制能够提高 Terminus-KIRA、能够优化 harness 源码、能够改善跨任务泛化、能够降低搜索成本，或能够证明本研究的外部方法知识库有效。这些都需要本地实验。
