# MAST

## 方法概要

MAST 从多 Agent 执行轨迹中归纳系统性失败模式，覆盖系统设计、Agent 协作以及验证和终止等层面，用于把“失败了”拆解为可定位的机制类别。

## 可迁移机制

- 按失败模式标注轨迹，而不是只记录最终分数。
- 区分单 Agent 行为、协作协议和系统终止条件。
- 用失败类别支持后续诊断和候选修改。

## 使用边界

MAST 面向多 Agent 系统；迁移到单 Agent Harness 时需要确认失败类别是否仍有意义。
