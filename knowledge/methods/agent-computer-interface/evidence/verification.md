## 主张边界

可以引用的结论是：接口设计（窗口化查看、编辑 guardrail、反馈信息量）是独立于模型能力的可影响 agent 表现的机制，论文在固定模型下给出了消融证据。

不能引用为已证实结论的内容包括：该接口能提高本研究 H0 的任务通过率、其 token/时延开销在预算内可接受、或优于现有 harness 的工具设计。这些都需要本地实验。
