# 实现依据

核对代码来源：[`princeton-nlp/SWE-agent`](https://github.com/princeton-nlp/SWE-agent)（论文对应 NeurIPS 2024 版本）。关键位置按上游模块粒度标注，精确文件路径待对照固定版本复核。

| 环节 | 论文/上游行为 | 关键位置 |
| --- | --- | --- |
| 命令集与配置 | 工具以固定命令集暴露；任务、工具与提示在配置文件中注册 | 上游配置与工具注册模块 |
| 窗口化查看 | 文件查看器每次显示固定行数（默认 100 行），带行号，支持滚动与搜索 | 上游查看工具（windowed viewer） |
| 编辑 guardrail | edit 命令写回后检查语法；错误编辑自动回退并反馈错误信息 | 上游编辑工具与 linter 集成 |
| 反馈格式 | 简洁而信息充分：成功无输出时明确说明，失败带原因 | 上游反馈/格式化模块 |

## 输入输出约定

```text
命令（view / edit / search）+ 参数 + 文件系统状态
                    ↓
   窗口化查看（行号 + 滚动 + 检索）
   带 guardrail 编辑（写回 → 检查 → 失败回退）
                    ↓
   面向模型的反馈（含空输出说明与错误定位）
```

## 本仓库代码

[`../code/aci_toolkit.py`](../code/aci_toolkit.py) 按上述机制重新实现为与 harness 无关的骨架，而非复制上游代码。差异：不执行真实 shell 命令，只保留查看、编辑与反馈三个机制；语法检查器可注入（默认对 Python 用 `ast.parse`）；反馈格式化集中在单个函数。迁移到 Terminus-KIRA 时，第一步是把现有文件工具包装为命令集并接入统一的反馈格式化，第二步再逐项加 guardrail；不能只改系统提示。

上游仓库当前未复制进仓库；其运行依赖和可复现性仍需通过实际复现确认。
