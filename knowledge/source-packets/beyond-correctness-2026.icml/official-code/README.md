# Beyond Correctness: Distance-Based Social Dynamics of Multi-Agent Debate (ICML 2026)

![Fig1](Fig1.png)

Open codebase for the paper "Beyond Correctness: Distance-Based Social Dynamics of Multi-Agent Debate" (accepted in ICML 2026, regular paper at the main track).
- File description
  - socialLLM_ConceptARC.py: Utilities and pre-defined methods.
  - socialLLM.ipynb: Notebook for conducting Stage I and II of the social trials.
  - socialLLM_figure.ipynb: Notebook for drawing figures.
- The dataset we used (ConceptARC) is fully open and available at github.com/victorvikram/ConceptARC.
- User-friendly manuals and instructions will be ready soon.
