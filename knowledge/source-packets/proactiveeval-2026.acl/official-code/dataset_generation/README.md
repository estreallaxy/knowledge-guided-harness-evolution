# This is the code of evaluation data generation in ProactiveEval
1. ``examples``: the icl shots in data generation.
2. ``prompt``: the all prompts in data generation.
3. ``topic_tree``: the final topic tree results in our dataset. 
4. ``data_generation.py``: include the all code in Environment & Target Generation in the ProactiveEval.
5. ``data_refinement.py``: include the code of obfuscation rewrite and noise injection in the pipeline.
