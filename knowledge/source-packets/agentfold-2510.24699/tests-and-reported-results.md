## Table 1（PDF p.8）主结果

| Agent | BrowseComp | BrowseComp-ZH | WideSearch | GAIA |
| --- | ---: | ---: | ---: | ---: |
| **AgentFold-30B-A3B（本文）** | **36.2** | **47.3** | **62.1** | **67.0** |
| DeepSeek-V3.1-671B-A37B（开源对照） | 30.0 | 49.2 | - | 63.1 |
| GLM-4.5-355B-A32B（开源对照） | 26.4 | 37.5 | - | 66.0 |
| OpenAI-o3（闭源对照） | 49.7 | 58.1 | 60.0 | 70.5 |
| OpenAI Deep Research（闭源对照） | 51.5 | 42.9 | - | 67.4 |

论文主张：30B 级模型超过更大的开源 agent，并接近部分闭源系统。WideSearch 用的是
**Item-F1**，GAIA 与另外两个 benchmark 的指标口径不同，不能直接横向平均。
