then takes the image, the generated spatiotemporal metadata,
and the surrounding multi-turn dialogue as joint inputs to
produce recall-type retrieval queries. The model conditions
on visual scene content, dialogue semantics, and the time-
space anchor so that each query reflects realistic memory-
triggering patterns rather than isolated image captioning.
Query generation follows five principles:
  1. Embed time and location as event anchors so recall
     is grounded in a specific scene, not detached visual
     content alone.
  2. Set the question time later than the event time to simu-
     late post-hoc recall rather than contemporaneous ques-
     tioning.
  3. Prefer relative temporal expressions (e.g., “last week,”
     “last month,” “that afternoon”) over explicit calendar
     dates, discouraging string matching and stressing tem-
     poral association.
  4. Use multi-turn dialogue to supply situational back-
     ground and user behavior, so queries leverage event
     context beyond what is visible in the image.
  5. Emphasize environmental, situational, and experiential
     details rather than simple factual QA, aligning queries
     with how humans trigger episodic memories.
Together, these stages turn raw image-centric interactions
into recall queries linked across time, space, and dialogue
context, yielding a more realistic long-term memory re-
trieval setting and a stronger test of temporal reasoning and
memory recall.
